# User flows

Diagrams for the student and admin journeys described in the [solution brief](./02-solution-brief.md), drawn in Excalidraw.

File: [`assets/user-flows.excalidraw`](./assets/user-flows.excalidraw). Open it at excalidraw.com and use File, then Open, to view or edit it.

Covers:

- Student: status page, papers, eligibility checks, payment, hall ticket
- Admin: cycle setup, form window, change handling, lock and publish, amendments
